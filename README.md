==========================================================
PROJECT NAME: Masroofy 
===========================================================

FILES INCLUDED:
1. MasroofyApp.java      : Main Program & Menu.
2. Entities.java         : Data models (Budget, Expense, Credentials).
3. Controllers.java      : Business logic and security services.
4. SystemInterfaces.java : Persistence (File Storage) and UI View.

TOOLS USED:
- Java JDK 17 (Coding)

HOW TO RUN:
- Compile: javac *.java
- Execute: java MasroofyApp

NOTE: This application uses file-based storage (.dat files) 
to save the budget and PIN automatically.
